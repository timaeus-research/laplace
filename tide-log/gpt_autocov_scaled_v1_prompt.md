# Tide 103 consult: β-scaled limits of the ULA long-run variance (laplace seabed, Lean 4 + Mathlib; E5 at the anchored scaling)

Landed (tide 102, `ULAAutocovariance.lean`): for the stationary ULA chain on `N(m, P⁻¹)` with step `h`, in any orthogonal frame diagonalising `P` (`p`) and `H` (`λ`): `ulaAutoCov ℓ = ½∑λᵢ²σᵢ⁴ρᵢ^{2ℓ} + ∑λᵢ²σᵢ²m̂ᵢ²ρᵢ^ℓ` (all lags, kernel-level definition), `ulaLongRunVar = ½∑λᵢ²σᵢ⁴(1+ρᵢ²)/(1−ρᵢ²) + ∑λᵢ²σᵢ²m̂ᵢ²(1+ρᵢ)/(1−ρᵢ) = ∑λᵢ²(1+ρᵢ²)/(4hpᵢ³κᵢ³) + 2∑λᵢ²m̂ᵢ²/(hpᵢ²)`, `σᵢ² = 1/(pᵢκᵢ)`, `ρᵢ = 1 − hpᵢ`, `κᵢ = 1 − hpᵢ/2`; finite-n lag-sum variance. Tides 99–100 (Multi): the anchored model `P_t = tH + g·1`, `pᵢ = tλᵢ + g`, anchored mean `m̂ᵢ = gŵᵢ/(tλᵢ+g)`; limit lemmas at `h = η/t`: `ulaScaledStep_factor_tendsto : tλ/((tλ+g)(1 − (η/t)(tλ+g)/2)) → 1/(1 − ηλ/2)` (needs `ηλ < 2`), `ulaScaledStep_var_main_tendsto : (t²/2)∑(λσ²)² → ½∑(1−ηλ/2)⁻²`, `ulaScaledStep_bias_tendsto`.

Candidates v1 (Claude):
A (Multi, fixed t,h). `ulaAnchored_autoCov`, `ulaAnchored_longRunVar`: tide 102's formulas instantiated on the anchored model with `m̂ᵢ = gŵᵢ/pᵢ`.
B (Limits, `h = η/t`, `0 < ηλᵢ < 2`, `g ≥ 0`). `ρᵢ(t) → 1 − ηλᵢ`; `IAT_quad = (1+ρᵢ²)/(1−ρᵢ²) → (1+(1−ηλᵢ)²)/(1−(1−ηλᵢ)²) = (1+(1−ηλᵢ)²)/(ηλᵢ(2−ηλᵢ))`; `IAT_lin = (1+ρᵢ)/(1−ρᵢ) → (2−ηλᵢ)/(ηλᵢ)`; main term `t²∑λᵢ²(1+ρᵢ²)/(4hpᵢ³κᵢ³) = ∑ (1+ρᵢ²)/(4ηλᵢ) · (tλᵢ/(pᵢκᵢ))³ → L_η := ∑ᵢ(1+(1−ηλᵢ)²)/(4ηλᵢ(1−ηλᵢ/2)³)`; mean term `2t²∑λᵢ²(gŵᵢ/pᵢ)²/(hpᵢ²) = (2/η)∑ g²ŵᵢ²(tλᵢ/pᵢ)³/(λᵢpᵢ) → 0`; so `t²τ²(t) → L_η` and, with eventual stability `(η/t)(tλᵢ+g) = ηλᵢ + ηg/t → ηλᵢ < 2`, `Tendsto (fun t => t² · ulaLongRunVar P_t H (η/t) m_t) atTop (𝓝 L_η)`.
C (Comparison). `t²c₀(t) → ½∑(1−ηλᵢ/2)⁻²`; per mode `[(1+(1−x)²)/(4x(1−x/2)³)]/[½(1−x/2)⁻²] = (1+(1−x)²)/(x(2−x))` (`x = ηλᵢ`): the limiting ratio of the long-run to the single-sample variance is the limiting quadratic IAT; effective sample size per mode `n·x(2−x)/(1+(1−x)²) ≈ nηλᵢ` for small `x`.
D (optional). `t² · lagSumVar n → (1/n²)∑ᵢ ½(1−ηλᵢ/2)⁻²(n + 2G_n((1−ηλᵢ)²))` for fixed `n`.

Numerical check (`λ = (1, 2.5)`, `g = 0.7`, `η = 0.3`): `t²τ²` = 3.2427 (t=10) → 3.4723 (t=10240) vs `L_η = 3.47251`; mean part 0.17 → 2.2e-4 (∝ 1/t); `t²c₀ → 1.97204` = `½∑(1−ηλ/2)⁻²`; IATs → 2.9216/1.1333 (quad), 5.6667/1.6667 (lin); the ratio of limits per mode equals the quadratic IAT limit.
