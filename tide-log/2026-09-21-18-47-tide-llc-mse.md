Notation: `LLĈ = t (1/(CN)) ∑_c ∑_{k<N} ½⟨x_c(b+1+k), H x_c(b+1+k)⟩` on the ULA chain for `P = tH`, `pᵢ` the eigenvalues of `tH`,
`ρᵢ = 1 − h pᵢ`, `Λ_h = ½ ∑ᵢ 1/(1 − h pᵢ/2)` the ULA LLC (`ula_llc`), `R₂ᵢ = ∑_{k<N} ρᵢ^{2(b+1+k)}`,
`shortfall = ½ ∑ᵢ (R₂ᵢ/N)/(1 − h pᵢ/2)` (so `E LLĈ = Λ_h − shortfall`), `inflation = Λ_h − d/2 = ½ ∑ᵢ (h pᵢ/2)/(1 − h pᵢ/2)`,
`envelope = 1/(2CN) ∑ᵢ (1 + ρᵢ²)/((1 − ρᵢ²)(1 − h pᵢ/2)²)`, `shortfall_bd = ½ ∑ᵢ ρᵢ^{2(b+1)}/(N(1 − ρᵢ²)(1 − h pᵢ/2))`.

## Candidates v1 (Claude)

**A. Scalar bias–variance decomposition.** For `X` with `X, X²` integrable under a probability measure and any `a : ℝ`,
`∫ (X − a)² = (∫ X² − (∫ X)²) + (∫ X − a)²`. (The per-entry content of `integral_sum_sq_sub_eq`; stated once for scalars.)

**B. MSE against the ULA LLC (exact and bounded).**
```
llc_mse_ula     : ∫ (LLĈ − Λ_h)² = Var(LLĈ) + shortfall²
llc_mse_ula_le  : ∫ (LLĈ − Λ_h)² ≤ envelope + shortfall_bd²
```
under `0 < h pᵢ ≤ 1` (the envelope's hypothesis; it implies the `h pᵢ < 2` of the mean theorems).

**C. MSE against the true LLC `d/2`.**
```
llc_mse_half_dim    : ∫ (LLĈ − d/2)² = Var(LLĈ) + (inflation − shortfall)²
llc_mse_half_dim_le : ∫ (LLĈ − d/2)² ≤ envelope + (inflation + shortfall_bd)²
```
(`inflation, shortfall ≥ 0`, so `|inflation − shortfall| ≤ inflation + shortfall_bd`.)

**D. The three error sources (RMS form).**
```
llc_rms_le : √(∫ (LLĈ − d/2)²) ≤ √envelope + inflation + shortfall_bd
```
via `√(a + b²) ≤ √a + |b|`: Monte Carlo `O(√(d/(CN)))`, discretisation `O(h pmax)`, burn-in `O(ρ_max^{2(b+1)}/N)` — the note's
"residual being the ULA inflation" and "very short single chains miss it" as the second and third terms. With
`sum_one_div_one_sub_bounds` the inflation is at most `(d/2)(h pmax/2)/(1 − h pmax/2)`; a corollary `llc_rms_le'` states the bound with
that spectrum-free form.
