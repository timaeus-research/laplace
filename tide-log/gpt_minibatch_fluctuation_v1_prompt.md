# Tide 104 consult: positivity of the Lyapunov stationary covariance and the minibatch fluctuation of the LLC statistic (laplace seabed, Lean 4 + Mathlib; E8)

Seabed: `diagLyapunov a N = of fun i j => N i j/(1 − aᵢaⱼ)` (entrywise solution of `X = diag(a) X diag(a) + N`), `lyapunovVia U a N = U·diagLyapunov a (UᵀNU)·Uᵀ` (unique fixed point of `X ↦ AXAᵀ + N` for `A = U diag(a) Uᵀ`, `|aᵢ| < 1`), `minibatchNoise h t C = 2h·1 + h²t²C`, frame entries `(UᵀΣ^{mb}U)ᵢⱼ = (2h[i=j] + h²t²Ĉᵢⱼ)/(1−ρᵢρⱼ)`, diagonal `(1 + ht²Ĉᵢᵢ/2)/(pᵢκᵢ)` (tide 101), the mean `(t/2)tr(HΣ^{mb}) = (t/2)∑λᵢ(1 + ht²Ĉᵢᵢ/2)/(pᵢκᵢ)` (only the frame diagonal of `C` enters). Tilted-Gaussian layer: `tiltedVar_quadForm : Var_{P,v}(uᵀHu) = 2∑ₐ∑_c(HP⁻¹)ₐ_c(HP⁻¹)_cₐ + 4(Hm)ᵀP⁻¹(Hm)` (needs `P.PosDef`); tide 102's stationary-law package (`Σ ≻ 0 ⇒` precision `Σ⁻¹`, tilt `Σ⁻¹m`). No positivity statement about `lyapunovVia`/the minibatch covariance exists yet. Mathlib here defines `PosDef`/`PosSemidef` via finitely supported vectors, with `posDef_iff_dotProduct_mulVec`/`posSemidef_iff_dotProduct_mulVec` characterisations.

Candidates v1 (Claude):
A. `x ⬝ᵥ diagLyapunov a N x = ∑'_{r≥0} (aʳ∘x) ⬝ᵥ N (aʳ∘x)` with `(aʳ∘x)ᵢ = aᵢʳxᵢ` (from `1/(1−aᵢaⱼ) = ∑'_r (aᵢaⱼ)ʳ`, `|aᵢaⱼ| < 1`, and two finite-sum/tsum swaps); hence `N ⪰ 0 ⇒ diagLyapunov a N ⪰ 0` and `N ≻ 0 ⇒ diagLyapunov a N ≻ 0` (the `r = 0` term: `xᵀ diagLyap x ≥ xᵀNx > 0`), transported to `lyapunovVia U a N ≻ 0`; `minibatchNoise h t C ≻ 0` for `h > 0`, `C ⪰ 0`; so `Σ^{mb} ≻ 0`.
B. `Var_{N(m,Σ^{mb})}(½uᵀHu) = ½∑ᵢ∑ⱼλᵢλⱼΣ̂ᵢⱼ² + ∑ᵢ∑ⱼλᵢλⱼm̂ᵢm̂ⱼΣ̂ᵢⱼ` (`Σ̂ = UᵀΣ^{mb}U`, `m̂ = Uᵀm`), via `tiltedVar_quadForm` and frame lemmas for a non-diagonal middle factor (`∑ₐ∑_c(UM₁Uᵀ)ₐ_c(UM₂Uᵀ)_cₐ = ∑ᵢⱼ(M₁)ᵢⱼ(M₂)ⱼᵢ`, `x ⬝ᵥ (UMUᵀ)y = (Uᵀx) ⬝ᵥ M(Uᵀy)`).
C. `Σ̂ᵢⱼ = σᵢ²[i=j] + Eᵢⱼ`, `Eᵢⱼ = h²t²Ĉᵢⱼ/(1−ρᵢρⱼ)`, `σᵢ² = 1/(pᵢκᵢ)`; `Var^{mb} − Var^{ULA} = ½∑ᵢⱼλᵢλⱼ(2σᵢ²[i=j]Eᵢⱼ + Eᵢⱼ²) + ∑ᵢⱼλᵢλⱼm̂ᵢm̂ⱼEᵢⱼ`; first-order diagonal part `∑ᵢλᵢ²σᵢ²Eᵢᵢ = (ht²/2)∑ᵢλᵢ²σᵢ⁴Ĉᵢᵢ` (the variance inflates to first order by the same per-mode factor `1 + ht²Ĉᵢᵢ/2` as the mean; off-diagonal `Ĉᵢⱼ` enters at `O(C²)`); `lyapunovVia` is linear in `N`, `lyapunovVia U ρ (2h·1) = ulaCov P h`, hence `Σ^{mb} − Σ^{ULA} = lyapunovVia U ρ (h²t²C) ⪰ 0`.
D (optional). `Var^{mb} ≥ Var^{ULA}` via monotonicity of `tr((HΣ)²)` and `mᵀHΣHm` in `Σ ⪰ 0` (needs `tr(BE) ≥ 0` for PSD `B, E`).

Numerical check (3D random frame, `t = 20`, `h = 0.3/t`, random PSD `C` scale 0.05): Lyapunov fixed point = frame formula (1e-17); series = quadratic form, first term ≤ it, `λ_min(Σ^{mb}) > 0`; `Var` exact = frame formula = Monte Carlo; the split, excess and first-order term check; `Σ^{mb} − Σ^{ULA}` has positive smallest eigenvalue.
