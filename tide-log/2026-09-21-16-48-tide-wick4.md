## Candidates v1 (Claude)

**A. The four-way Isserlis identity.** For `hT : FourthMomentTable g P v`, `s : Finset κ`, `a b c d : κ → R`, with `X = ∑_{i∈s} a_i g_i` etc.:
`∫ X Y Z W = v^2 (<a,b><c,d> + <a,c><b,d> + <a,d><b,c>)` (sums over `s`). Induction on `s`: with `G = g_n`, `n ∉ s`,
`(X+αG)(Y+βG)(Z+γG)(W+δG) = XYZW + G(αYZW + βXZW + γXYW + δXYZ) + G^2(αβ ZW + αγ YW + αδ YZ + βγ XW + βδ XZ + γδ XY)
+ G^3(αβγ W + αβδ Z + αγδ Y + βγδ X) + αβγδ G^4`; the `G` and `G^3` groups vanish (`E G = E G^3 = 0`, the quadruple `(X,Y,Z,W)` independent of `G`),
the `G^2` group gives `v` times second moments (`integral_linComb_mul`), `E G^4 = 3v^2`; the closed form for `insert n s` follows by algebra.
Needs: block independence of the *quadruple* (a `Fin 4 → R`- or nested-pair-valued map of the block) generalising `indepFun_pair_of_isLinComb`,
and the factorisation lemma for `φ : R × R × R × R → R` (or `Fin 4 → R → R`).
**B. Corollary: the covariance of products.** `∫ (XY)(ZW) - (∫ XY)(∫ ZW) = v^2(<a,c><b,d> + <a,d><b,c>)` — the object that enters
`Var(Σ̂_ij)` and hence the Frobenius error of the pooled covariance.
**C (follow-up, not this tide).** The whole-covariance E4 law: `E|Σ̂ - Σ|_F^2 = ∑_{ij} Var(Σ̂_ij)` for the pooled uncentred second-moment matrix
of the ULA chain, using B along each pair of eigendirections and the independence of the projected innovations across eigendirections
(Mathlib's `iIndepFun.hasGaussianLaw_pi` + `HasGaussianLaw.iIndepFun_of_covariance_inner`).

Proposed: A + B, one module `Laplace/Sampler/Wick4.lean` (~350 lines).
