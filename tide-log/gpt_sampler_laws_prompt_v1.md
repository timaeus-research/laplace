## Candidates v1 (Claude)

**Candidate A (Lyapunov laws, pure linear algebra).**
(A1) Fixed point. If P is positive definite and 0 < lr with lr·P < 2I (i.e. lr·λ_max(P) < 2), then Σ_ULA := P⁻¹ (I - (lr/2) P)⁻¹ = (P - (lr/2)P²)⁻¹ is symmetric positive definite and satisfies Σ_ULA = A Σ_ULA A + 2 lr I. (The proof is commutative algebra: Σ_ULA commutes with P.)
(A2) Neumann series, uniqueness, finite-chain formula. If ‖A‖ < 1 in operator norm (for symmetric A this is: all eigenvalues in (-1,1)), then for every symmetric N the Lyapunov equation Σ = A Σ Aᵀ + N has exactly one solution, Σ_∞ = Σ_{k≥0} A^k N (Aᵀ)^k; the recursion Σ_{k+1} = A Σ_k Aᵀ + N started at Σ_0 = 0 gives Σ_k = Σ_{j<k} A^j N (Aᵀ)^j and Σ_k → Σ_∞; and if N commutes with A then Σ_k = Σ_∞ (I - A^{2k}) and Σ_∞ = (I - A²)⁻¹ N.
(A3) Corollaries. With N = 2lr I this recovers A1 (so Σ_ULA is the unique fixed point); with N = 2 lr I + lr² t² C and C commuting with P (e.g. diagonal in the eigenbasis of P) the per-eigendirection variance is (1 + lr t² c_i/2) / (p_i (1 - lr p_i/2)), where c_i is the eigenvalue of C on that direction. In one dimension (d = 1, ρ = 1 - lr p, σ² = 2lr/(1-ρ²)) A2 gives Var(x_k) = σ²(1 - ρ^{2k}) for a chain started at 0.

**Candidate B (Gaussian invariance, probabilistic).** For X ~ multivariateGaussian 0 Σ on EuclideanSpace ℝ ι (Σ positive semidefinite) and ξ ~ multivariateGaussian 0 I independent of X, the law of A X + √(2 lr) ξ is multivariateGaussian 0 (A Σ Aᵀ + 2 lr I). Consequently multivariateGaussian 0 Σ_ULA is invariant under one ULA step on the Gaussian target with precision P (given A1). **Candidate C (localised Gaussian LLC identity, in the seabed's own language).** For the quadratic potential L(w) = ½ wᵀ H w and the localised weight exp(-t L(w) - (γ/2)|w|²) = exp(-½ wᵀ (tH + γI) w), the Gibbs expectation of K = L equals ½ tr(H (tH + γI)⁻¹); hence t⟨K⟩ = d/2 when γ = 0 and t⟨K⟩ = ½ Σ_i tλ_i/(tλ_i + γ) in general.
