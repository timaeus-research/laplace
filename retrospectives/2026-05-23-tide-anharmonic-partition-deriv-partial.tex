\section{Why stop here}

The \texttt{partition\_hasDerivAt} proof itself was attempted but
abandoned mid-write per the laplace \texttt{CLAUDE.md} thrashing rule.
The structure is clear:

\begin{enumerate}[noitemsep,leftmargin=*]
\item Apply \texttt{MeasureTheory.hasDerivAt\_integral\_of\_dominated\_loc\_of\_deriv\_le}.
\item Need a bound function $\mathrm{bound}(x) := |t \cdot x| \cdot \exp(-t \cdot L_{\rm anh}(x)) \cdot \exp(t \cdot |x|)$.
  Integrability follows from coercivity + AM-GM:
  $|x| \leq (c/2) x^2 + 1/(2c)$ gives
  $-tc \cdot x^2 + t |x| \leq -(tc/2) x^2 + t/(2c)$, so
  $\mathrm{bound}(x) \leq |t \cdot x| \cdot \exp(t/(2c)) \cdot \exp(-(tc/2) x^2)$,
  Gaussian-integrable via the $n=1$ Mathlib lemma.
\item Pointwise derivative via chain rule of \texttt{HasDerivAt.exp},
  \texttt{HasDerivAt.const\_add}, etc.
\item Discharge AE-measurability conditions via continuity.
\end{enumerate}

Estimated $\sim 80$--$120$ lines of bounded but technically involved
Lean. Without an MCP Lean LSP for iterative goal-state inspection,
attempting this in one shot via \texttt{lake build} is high-risk
thrashing. The partial commit here lands one of the four pieces;
the remaining three are still pending.

\section{Pipeline lessons}

\begin{itemize}[noitemsep,leftmargin=*]
\item \textbf{Partial-progress commits are valuable.} Even one
  integrability lemma is reusable: the next session attempting the
  full proof can call \texttt{integrable\_x\_mul\_exp\_neg\_t\_anharmonic}
  directly without re-deriving.
\item \textbf{Mirror the existing $n=0$ pattern when adding $n=k$.}
  The integrability proofs in this file follow a strict template:
  \texttt{anharmonic\_coercive} $\Rightarrow$ Gaussian dominator
  $\Rightarrow$ \texttt{Integrable.mono} $\Rightarrow$ pointwise
  inequality via \texttt{Real.exp\_le\_exp.mpr} + \texttt{linarith}.
  Future $n=2, 3, \ldots$ instances should be ~30-line copy-edits.
\end{itemize}
