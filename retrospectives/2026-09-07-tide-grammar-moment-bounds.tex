\begin{abstract}
The constants of the density-transfer theorem (unit~83), the weighted remainder moment $M_H$ and the
tail moments $T_i$, are bounded explicitly by the log-weighted kernel moments
$\Lambda_{\gamma,j}(a')=\int_0^\infty s^\gamma(1+|\log s|)^je^{-\beta s^2+\beta a's}\,ds$ under the
polynomial-exponential bound $|c(s)|\le e^{\beta sa'}(A+Bs+Ds^2)$. Since $\Lambda_{\gamma,j}$ is
monotone in $a'$, the bounds are uniform over face parameters $|a|\le L$, the input for the
second-order theorem with noncritical coordinates. The third GPT-6 Astra consult
(\texttt{tide-log/gpt6\_bigpicture\_v3.md}) fixes the architecture of the all-order theory: finite
compatible jets with moment-integrable remainders as the engine, analyticity only as a provider of jets
and of coefficient-series representations. Zero \texttt{sorry}/\texttt{axiom}.
\end{abstract}

  ∫ s in Ioi (0 : ℝ), (1 + |Real.log s|) ^ j * (s ^ γ * quadKernel β a s)
theorem logKernelMoment_mono (β γ : ℝ) (hβ : 0 < β) (hγ : -1 < γ) (j : ℕ) {a a' : ℝ}
    (haa : a ≤ a') : logKernelMoment β a γ j ≤ logKernelMoment β a' γ j
theorem tailMoment_le_of_bound (β a' a A B D : ℝ) (hβ : 0 < β) (ha : -1 < a - 1)

    (hbound : ∀ s, 0 < s → |c s| ≤ Real.exp (β * s * a') * (A + B * s + D * s ^ 2)) :
    tailMoment β a j c ≤ A * logKernelMoment β a' (a - 1) j + B * logKernelMoment β a' a j
